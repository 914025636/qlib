# 分钟级高频交易常用因子

> 适用范围：分钟/秒级 K 线 + 逐笔成交（trades）+ 订单簿快照（orderbook）。
> 本工作区数据为 Binance 加密货币现货（`BTC/USDC`），字段见文末「本地数据落地」一节。

---

## 一、价格动量 / 反转

| 因子 | 构造 | 说明 |
|---|---|---|
| 多周期收益率 | `close / delay(close, N) - 1`，N = 5/10/30/60 | 趋势延续 |
| 隔夜跳空 | `open_t / close_{t-1} - 1` | 传统股票适用；7×24 市场退化为周期切换 |
| 日内位置 | `(close - low_d) / (high_d - low_d)` | 归一化区间位置 |
| 短周期反转 | `-(close / delay(close, 1..5) - 1)` | 高频反转效应显著，衰减极快 |
| 残差动量 | 对基准（指数 / BTC）回归后的残差累积 | 剥离市场 beta |

## 二、成交量 / 量价关系

| 因子 | 构造 |
|---|---|
| 量比 | `volume / mean(volume, N)` |
| 单笔成交均额 | `amount / trade_count`（识别大单） |
| 量价相关性 | `corr(close, log(volume), N)` |
| 收益-量变相关 | `corr(ret, Δvolume, N)` |
| 主动买卖净额 | `sum(sign * amount, N)`，`sign` 由 taker 方向给出 |
| 买卖不平衡（成交侧） | `(buy_amt - sell_amt) / (buy_amt + sell_amt)` |
| 大单净流入 | 仅统计 `qty > quantile(qty, 0.9)` 的净额 |

## 三、波动率 / 高阶矩

| 因子 | 构造 | 说明 |
|---|---|---|
| 已实现波动 RV | $RV=\sum_{i} r_i^2$ | 分钟内高频收益平方和 |
| 已实现偏度 | $RSkew = \frac{\sqrt{n}\sum r_i^3}{RV^{3/2}}$ | 尾部方向 |
| 已实现峰度 | $RKurt = \frac{n\sum r_i^4}{RV^{2}}$ | 尾部厚度 |
| 上下行半方差比 | $RSV^{+}/RSV^{-}$ | 非对称风险 |
| Parkinson | $\sqrt{\frac{1}{4\ln 2}\ln^2(H/L)}$ | 区间波动 |
| Garman-Klass | 含 OHLC 的方差估计 | 效率高于收盘波动 |
| 跳跃成分 | $RV - BPV$（双幂变差） | 分离连续波动与跳跃 |

## 四、订单簿微观结构（需 L2）

| 因子 | 构造 |
|---|---|
| 中间价 | `(bid1 + ask1) / 2` |
| 微观价格（加权中间价） | `(bid1 * askSz1 + ask1 * bidSz1) / (bidSz1 + askSz1)` |
| 订单簿不平衡 OBI | `(bidVol - askVol) / (bidVol + askVol)`，可取前 1/5/10 档 |
| 相对价差 | `(ask1 - bid1) / mid` |
| 订单流不平衡 OFI | 逐档挂单量增量的方向加权累加 |
| 深度斜率 | 累积挂单量对价格偏离的回归斜率 |
| 撤单率 | `cancel_qty / (add_qty + cancel_qty)` |
| 价差偏离 | `(last_price - mid) / spread` |

## 五、流动性 / 冲击成本

| 因子 | 构造 |
|---|---|
| Amihud 非流动性 | `mean(|ret| / amount, N)` |
| Kyle's Lambda | `ret` 对净成交量的回归斜率 |
| VWAP 偏离 | `close / vwap - 1` |
| 有效价差 | `2 * |last_price - mid| / mid` |

## 六、日内形态 / 时序

- 时段特征：开盘 / 尾盘（股票 U 型效应）；加密市场用 UTC 小时哑变量、亚/欧/美盘时段
- 分钟收益自相关 `autocorr(ret, lag=1..5)`
- Hurst 指数（趋势 vs 均值回复）
- 跨品种领先滞后：`corr(ret_BTC(t-k), ret_ALT(t))`

## qlib 表达式示例

```python
fields = [
    "$close/Ref($close, 30) - 1",                                   # 30 分钟动量
    "-($close/Ref($close, 3) - 1)",                                 # 短周期反转
    "Std($close/Ref($close,1) - 1, 60)",                            # 已实现波动
    "$volume/Mean($volume, 60)",                                    # 量比
    "Corr($close, Log($volume+1), 30)",                             # 量价相关
    "Sum(Greater($close-Ref($close,1),0)*$volume, 30)/Sum($volume, 30)",  # 上涨量占比
    "Mean(Abs($close/Ref($close,1)-1)/($money+1), 30)",             # Amihud
    "($high-$low)/$close",                                          # 区间波动
    "($close-$low)/($high-$low+1e-12)",                             # 日内位置
]
```

## 本地数据落地

### `trades参考`（逐笔成交）

```
exchange, symbol, side, price, quantity, trade_id, timestamp
```

`side` 为 taker 方向，可直接算主动买卖不平衡：

```python
import pandas as pd

tr = pd.read_csv("trades参考", parse_dates=["timestamp"])
tr["amt"] = tr.price * tr.quantity
tr["signed"] = tr.amt.where(tr.side == "buy", -tr.amt)

g = tr.set_index("timestamp").groupby(pd.Grouper(freq="1min"))
bar = pd.DataFrame({
    "open":  g.price.first(),
    "high":  g.price.max(),
    "low":   g.price.min(),
    "close": g.price.last(),
    "vol":   g.quantity.sum(),
    "amt":   g.amt.sum(),
    "n":     g.trade_id.count(),
    "ofi_trade": g.signed.sum() / g.amt.sum(),   # 成交侧买卖不平衡
    "avg_trade_size": g.amt.sum() / g.trade_id.count(),
})
bar["vwap"] = bar.amt / bar.vol
bar["vwap_dev"] = bar.close / bar.vwap - 1
```

### `orderbook参考`（订单簿增量/快照）

```
exchange, symbol, side, update_type, price, qty, sequence, source_update_count, timestamp
```

- `update_type = snapshot | update`；`qty = 0` 视为该价位撤单
- 需按 `sequence` 顺序重建盘口，再在分钟末采样

```python
ob = pd.read_csv("orderbook参考", parse_dates=["timestamp"])

# 重建盘口：按 sequence 回放，qty==0 删除该档
book = {"bid": {}, "ask": {}}
snapshots = []
for seq, chunk in ob.sort_values("sequence").groupby("sequence"):
    if (chunk.update_type == "snapshot").any():
        book = {"bid": {}, "ask": {}}
    for r in chunk.itertuples():
        side = book[r.side]
        if r.qty == 0:
            side.pop(r.price, None)
        else:
            side[r.price] = r.qty
    if not book["bid"] or not book["ask"]:
        continue
    bids = sorted(book["bid"].items(), reverse=True)[:10]
    asks = sorted(book["ask"].items())[:10]
    bv, av = sum(q for _, q in bids), sum(q for _, q in asks)
    b1, a1 = bids[0], asks[0]
    mid = (b1[0] + a1[0]) / 2
    snapshots.append({
        "timestamp": chunk.timestamp.iloc[-1],
        "mid": mid,
        "micro_price": (b1[0]*a1[1] + a1[0]*b1[1]) / (b1[1] + a1[1]),
        "spread_rel": (a1[0] - b1[0]) / mid,
        "obi1": (b1[1] - a1[1]) / (b1[1] + a1[1]),
        "obi10": (bv - av) / (bv + av),
    })

snap = pd.DataFrame(snapshots).set_index("timestamp")
ob_bar = snap.resample("1min").agg(["last", "mean", "std"])
```

## 实操要点

1. **半衰期短**：分钟级 alpha 通常在分钟到小时级衰减，需按持仓周期匹配因子窗口
2. **交易成本主导**：手续费 + 滑点常吞掉毛收益，回测必须含 taker/maker 费率与冲击成本
3. **异常值处理**：集合竞价、涨跌停（股票）、插针行情（加密）需截断或 winsorize
4. **时间对齐**：订单簿与成交流用同一时钟；避免用未来盘口算当期因子（look-ahead）
5. **中性化**：股票需行业/市值中性；加密可对 BTC 收益做 beta 中性
6. **样本外验证**：分钟级样本量大易过拟合，需 purged K-fold + embargo
7. **存储与计算**：逐笔数据量大，建议落到 Parquet/QuestDB（本仓库已有 [qlib/scripts/questdb_to_qlib.py](qlib/scripts/questdb_to_qlib.py)）
