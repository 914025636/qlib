# 震荡市均值回归套利策略：因子与标签设计

本目录实现一套**震荡市均值回归**（Mean Reversion）策略，与 `examples/trend_following` 的趋势跟踪策略互为镜像、互补配置。

| 文件 | 作用 |
|---|---|
| `handler.py` | 均值回归因子集（28 个）+ 3 种可选标签 |
| `strategy.py` | regime 门控 / 限时持仓 / 目标止盈 / 崩盘熔断的组合策略 |
| `workflow_mr.py` | 端到端流程：训练 → 信号分析 → 回测 |

运行：

```powershell
cd f:\Python\AiQuantization\qlib
python examples/mean_reversion/workflow_mr.py
```

---

## 一、与趋势跟踪的镜像关系

两套策略赚的是同一个现象的两半：价格围绕价值波动。

| 维度 | 趋势跟踪 | 均值回归（本方案） |
|---|---|---|
| 盈利来源 | 价格**离开**均值的过程 | 价格**回到**均值的过程 |
| 适用行情 | 单边市（高 $R^2$、高效率比） | 震荡市（低 $R^2$、低效率比） |
| 入场信号 | 创新高、均线多头排列 | 深度超卖、布林下轨、恐慌放量 |
| 持仓逻辑 | 迟滞出场，让利润奔跑 | **快进快出**，回归即离场 |
| 持仓期 | 5 日起、趋势延续可无限期 | 2 日目标、5 日强制离场 |
| 最大风险 | 震荡市反复止损（whipsaw） | 趋势市"接飞刀"（catching falling knife） |
| 风险应对 | `min_n` 空仓兜底 | **regime 门控 + 崩盘熔断 + 时间止损** |

正因为互补，两套策略的 regime 判断用了**同一个指标**（指数 20 日 Kaufman 效率比）：趋势策略在高 ER 时活跃，本策略在低 ER 时活跃，理论上可以叠加成全天候组合。

## 二、标签设计

代码位置：`handler.py` 的 `get_mr_label_config()`。持仓期缩短到 **2 日**——均值回归的超额收益衰减极快，5 日窗口会稀释信号。

### 1. `risk_adj_ret`（默认）

$$\text{label}=\frac{P_{t+3}/P_{t+1}-1}{\sigma_{20}\sqrt{2}}$$

```python
(Ref($close,-3)/Ref($close,-1)-1)/(Std($close/Ref($close,1)-1,20)*1.414214+1e-4)
```

与趋势跟踪同构，仅前瞻窗口不同。CSI300 / 2017H1 实测：均值 0.039、标准差 1.20，`buy_thresh=0.5` 约为 79% 分位，比趋势策略（0.3）更苛刻——**逆势接单必须只做最深的偏离**。

### 2. `fwd_ret`

原始 2 日前瞻收益，适合外接独立风控。

### 3. `revert_to_mean`

$$\text{label}=\left|\frac{P_t}{\text{MA}_{20}(t)}-1\right|-\left|\frac{P_{t+3}}{\text{MA}_{20}(t+3)}-1\right|$$

```python
Abs($close/Mean($close,20)-1)-Abs(Ref($close,-3)/Ref(Mean($close,20),-3)-1)
```

直接度量**偏离的收敛量**：当前偏离减未来偏离，正值表示价格正在向均线收敛。与前两者的区别在于它对方向中性——超买回落和超卖反弹都算"回归"。若后续扩展做空腿（融券/股指对冲），这个标签可以直接复用。

标签处理器与趋势跟踪一致：**只有 `DropnaLabel`，无 `CSZScoreNorm`**，保留绝对量纲，否则阈值入场与 regime 择时全部失效。

## 三、因子设计

代码位置：`handler.py` 的 `get_mr_feature_config()`，28 个因子分 9 组。

设计原则：回答三个问题——**偏离有多深？现在是震荡市吗？抛售到尾声了吗？**

与趋势跟踪因子集刻意零重叠的部分：不含长周期动量（ROC60/120）、不含新高距离（HIGHDIST）、不含均线多头排列——这些是趋势因子，混入会让模型学出"趋势市也接单"的错误映射。

### 1. 布林位置（3 个）— 偏离深度 ★核心

```python
($close-Mean($close,w))/(Std($close,w)+1e-12)   # w ∈ {5,10,20}
```

价格偏离均线几个标准差，是均值回归最经典的入场依据。$-2\sigma$ 以下为深度超卖。多窗口并列让模型学"短期深跌但长期仍在通道内"这类组合形态。

### 2. 短期反转动量（4 个）

```python
$close/Ref($close,w)-1   # w ∈ {1,2,3,5}
```

近几日跌幅。注意与趋势跟踪的解读**方向相反**：在那边 ROC 越正越好，在这边模型应学出"ROC 深负 + 震荡市 → 未来反弹"。

### 3. RSI 强弱（2 个）

```python
Mean(Greater($close-Ref($close,1),0),w)/(Mean(Abs($close-Ref($close,1)),w)+1e-12)
```

Cutler's RSI（用 SMA 而非 Wilder 平滑，qlib 表达式引擎下等价且更简洁）。`Greater(x,0)` 取上涨日的涨幅、`Abs` 取总波动，比值低于 0.3 即传统意义的超卖。

### 4. 通道位置（2 个）

```python
($close-Min($low,w))/(Max($high,w)-Min($low,w)+1e-12)
```

贴近 0 为超卖。与趋势跟踪共用表达式但用法相反：那边找贴近 1（突破），这边找贴近 0（回归起点）。

### 5. 震荡市识别（4 个）— regime 的个股侧 ★核心

```python
Abs($close/Ref($close,w)-1)/(Sum(Abs($close/Ref($close,1)-1),w)+1e-12)  # Kaufman 效率比
Rsquare($close,w)                                                        # 趋势拟合优度
```

**效率比（ER）= 净位移 / 路径总长**。20 日走了很远且一路直线，ER→1（趋势市）；20 日上蹿下跳最终回到原点，ER→0（震荡市）。

这是本方案的安全阀：`BOLL20=-2.5` 在震荡市是黄金买点，在下跌趋势中是死亡陷阱。ER 和 $R^2$ 双低时前者成立。

### 6. 均值锚点稳定性（2 个）

```python
Slope(Mean($close,20),10)/$close   # 均线自身斜率
$close/Mean($close,20)-1           # 对均线的乖离
```

均值回归隐含假设"均线是价格的引力中心"。**均线本身在陡峭下行时，回归目标是移动的**——价格追着下行的均线跑，永远回不去。`MASLOPE≈0`（均线走平）时锚点才可靠。

### 7. 恐慌确认（3 个）

```python
If($close<Ref($close,1),$volume/(Mean($volume,20)+1e-12),0)   # 下跌日量比
($high-$low)/(Ref($close,1)+1e-12)                             # 日内振幅
($close-$low)/($high-$low+1e-12)                               # 收盘在日内区间的位置
```

抄底的经典问题是"底在哪"。两个微观结构信号：

- **PANICVOL**：下跌伴随异常放量 = 恐慌性抛售（capitulation），卖压集中释放往往是尾声；
- **CLOSEPOS**：低开高走收在日内高位（→1）说明买盘已开始承接，比单纯"跌得深"多一层企稳确认。

### 8. 波动率（3 个）

```python
Std($close/Ref($close,1)-1,w)                                   # w ∈ {10,20}
Std($close/Ref($close,1)-1,5)/(Std($close/Ref($close,1)-1,60)+1e-12)  # VOLRATIO
```

`VOLRATIO > 1` 表示短期波动相对长期正在放大——区分"正常回调"（波动平稳）和"波动率爆炸"（结构性风险）。后者不该接。

### 9. 市场状态（6 个）

```python
ChangeInstrument('SH000300', ER20 / Rsquare / ROC5 / ROC20 / VOL20)
```

指数层面的震荡判定与崩盘监测，与策略侧的硬门控（见下文）形成软硬两层：模型从这些特征里学出连续的 regime 权重，策略侧再用硬阈值兜底。

## 四、策略设计

代码位置：`strategy.py`。与趋势跟踪同样继承 `WeightStrategyBase` + 波动率定权 + 允许空仓，但持仓生命周期管理完全不同——均值回归的仓位是**有保质期的**。

### 出入场状态机

```
                 ┌──────────── 崩盘熔断 (指数5日 < -6%) ────────────┐
                 │                    全部清仓                      │
                 ▼                                                 │
  空仓 ──[震荡市 & score≥0.5]──▶ 持仓 ──┬─[score<0.1 止盈离场]──▶ 空仓
                 ▲                      ├─[持有≥5日 时间止损]──▶ 空仓
   [趋势市: 停止开新仓]                  └─[否则继续持有]
```

四条规则的动机：

1. **regime 门控**（`regime_er_thresh=0.35`）：指数 20 日 ER 高于阈值判定为趋势市，**停止开新仓但不强平存量**——趋势确立时超卖股会继续超卖，此时接单是逆水行舟；
2. **目标止盈**（`exit_thresh=0.1`）：预测值跌回 0.1 以下说明偏离已收敛，收益兑现立即走人。与趋势跟踪的迟滞持有正相反——均值回归的利润**不会奔跑**，回归完成后继续持有只剩噪声；
3. **时间止损**（`max_hold_days=5`）：回归要么几天内发生要么不发生。超期未回归说明这不是超卖而是基本面恶化，无条件离场。这是均值回归策略最重要的风控——它天然倾向于"死扛"亏损仓位（越跌信号越强），必须用时间维度强制打断；
4. **崩盘熔断**（`crash_thresh=-0.06`）：指数 5 日跌超 6% 时清仓一切。系统性下跌中"均值"本身在坍塌，所有个股信号失效。

验证结果（构造面板）：

```
1 震荡市/空仓   score={A:0.9,B:0.6,C:0.3,D:0.05,E:0.55}
               -> 买入 {A,B,E}          # C(0.3)<buy_thresh 不入场
2 C,D 持仓中    -> {A,B,E,C}            # C(0.3)>exit_thresh 继续持有；D(0.05) 止盈离场
3 A 持有 5 日   -> {}                   # 超期强制离场，即使 score=0.9
4 趋势市(ER=0.6)-> {A: 1.0}             # 存量保留，新仓 B/E 被门控拦截
5 崩盘(ret5=-8%)-> {}                   # 熔断清仓
```

注意情形 2 与 3 的对比：同一只 A，score 都是 0.9，只因持有天数不同而结果相反——**时间止损优先级高于信号强度**，这正是防"死扛"的设计。

### 与趋势跟踪的参数对照

| 参数 | 趋势跟踪 | 均值回归 | 差异原因 |
|---|---|---|---|
| 入场阈值 | 0.3 | **0.5** | 逆势接单要求更高置信度 |
| 出场逻辑 | 迟滞持有（sell_thresh=0.0） | **止盈+限时**（exit=0.1, 5日） | 利润不奔跑 |
| max_n | 50 | **20** | 深度超卖本就稀少，摊薄无意义 |
| target_vol | 0.02 | **0.015** | 接单标的波动本身偏高，压低单股风险 |
| max_weight | 0.05 | **0.08** | 持仓少，允许单股稍集中 |

## 五、参数调节

| 参数 | 默认 | 调节方向 |
|---|---|---|
| `buy_thresh` | 0.5 | ↑ 只做极端偏离，交易更少更准 |
| `exit_thresh` | 0.1 | ↑ 更早止盈，换手更高 |
| `max_hold_days` | 5 | ↓ 更严的时间止损；须 ≥ `HOLDING_DAYS` |
| `regime_er_thresh` | 0.35 | ↓ 更容易判定趋势市、更保守 |
| `crash_thresh` | -0.06 | ↑（如 -0.04）熔断更敏感 |
| `HOLDING_DAYS` | 2 | 标签前瞻窗口，改动须同步调 `max_hold_days` |

## 六、必须注意的坑

### 1. 逆势策略的回测幸存者偏差更严重

均值回归天然偏好买"跌得最惨"的股票，而 A 股跌得最惨的常是即将 ST/退市的标的。回测里它们可能"回归"，实盘中可能直接停牌。建议：

- 股票池坚持用 csi300/csi500 等指数成分（本配置默认），不要扩到全市场；
- 关注回测持仓明细里是否反复出现问题股。

### 2. 涨跌停制度对本策略影响远大于趋势跟踪

深度超卖股常伴随跌停。跌停日 `limit_threshold` 会禁止买入（回测正确处理），但实盘中"跌停打开瞬间"的成交价远差于收盘价。回测收益应打折看待，`deal_price="close"` 是偏乐观的假设。

### 3. 时间止损与标签窗口的一致性

标签学的是"未来 2 日收益"，策略允许持有 5 日。这个不对称是刻意的——每天都会用最新预测值重新评估持仓（score ≥ exit_thresh 才保留），相当于滚动续约 2 日预测；5 日是续约次数的上限而非独立假设。但如果把 `HOLDING_DAYS` 改大，`max_hold_days` 必须同步 ≥ 它，否则模型学的收益还没实现就被强制卖出。

### 4. 评价口径

与趋势跟踪相同：**不要看 IC**。重点看：

- 胜率与盈亏比：健康的均值回归应当是**高胜率、低盈亏比**（大量小赢 + 少量止损），与趋势跟踪的低胜率高盈亏比正相反；
- 熔断与门控的触发记录（日志中的 `market crash` / 空仓天数）：2018 年单边熊市中本策略应当长期停工，若依然满仓说明 regime 门控失效；
- 与趋势跟踪净值曲线的相关性：理想情况下两者低相关甚至负相关，可等权叠加。
