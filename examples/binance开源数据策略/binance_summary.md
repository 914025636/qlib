# Binance 历史订单簿数据与量化研究指南

## 数据来源与目录

- [Binance Data Vision](https://data.binance.vision/)：官方公共数据，按 `daily`（每日）或 `monthly`（每月）归档。
- `um` = USDⓈ-M（U本位，USDT/USDC 结算），常见符号 `BTCUSDT`。
- `cm` = COIN-M（币本位，标的币结算），常见符号 `BTCUSD_PERP`。

| 目录 | 内容 |
|---|---|
| `aggTrades/` | 聚合成交 |
| `trades/` | 更细粒度成交 |
| `bookDepth/` | 按百分比区间聚合的累计深度 |
| `bookTicker/` | 最优买卖价和数量（L1） |
| `klines/` | 合约成交价 OHLCV |
| `indexPriceKlines/` | 指数价格 K线 |
| `markPriceKlines/` | 标记价格 K线 |
| `premiumIndexKlines/` | 溢价指数 K线 |
| `metrics/` | 持仓量、多空比等指标 |

`daily/` 适合指定日期，`monthly/` 适合批量下载整月；并非所有数据类型都有月度版本。

## `bookDepth` 字段

| 字段 | 含义 |
|---|---|
| `timestamp` | 深度快照时间（通常 UTC） |
| `percentage` | 相对参考价的带符号距离；负数为 bid，正数为 ask |
| `depth` | 该区间的累计数量 |
| `notional` | 该区间的累计名义价值 |

例如 `-1` 是参考价下方 1% 内的累计买方深度，`+1` 是上方 1% 内的累计卖方深度。它们是累计区间，`-5` 不能再与 `-4`、`-3` 相加。`bookDepth` 是摘要，不是完整逐档 L2/L3。

## 推荐因子

### 主动成交不平衡

```text
OFI = (主动买成交量 - 主动卖成交量)
      / (主动买成交量 + 主动卖成交量)
```

### L1 盘口不平衡与点差

```text
I = (买一数量 - 卖一数量) / (买一数量 + 卖一数量)
spread = (卖一价 - 买一价) / 中间价
```

### 深度不平衡

```text
D_k = (bid_depth_k - ask_depth_k)
      / (bid_depth_k + ask_depth_k)
```

可取 `k = 0.2%、1%、2%、5%`。

### OI 与价格

| 价格 | OI | 常见解释 |
|---|---|---|
| 上涨 | 上升 | 新多头进入，趋势可能延续 |
| 上涨 | 下降 | 空头回补，行情可能衰竭 |
| 下跌 | 上升 | 新空头进入 |
| 下跌 | 下降 | 多头平仓或清算 |

### 基差

```text
basis = (合约价格 - 指数价格) / 指数价格
```

## 可优先测试的策略

1. **成交流趋势**：OFI 高分位、价格同向、OI 上升、1% 深度不平衡同向时入场。
2. **吸收/反转**：主动买很多但价格不涨，或主动卖很多但价格不跌。
3. **OI-价格四象限**：同向时测试动量，平仓/回补状态测试反转。
4. **基差/资金费率收敛**：基差、资金费率和 OI 同时极端时做对冲收敛。
5. **流动性过滤**：spread 高分位或深度骤降时降低仓位、禁止开仓。

## 第一版特征

```text
ret_5m, ret_30m, ofi_5m, ofi_30m,
book_imbalance, depth_imbalance_1pct,
delta_oi_30m, basis_zscore
```

预测未来 15 分钟和 1 小时收益，使用滚动样本外测试，评估 IC、分组收益、最大回撤、换手率以及手续费和滑点后的净收益。

## 注意事项

1. 信号至少向后移动一个 bar，避免未来函数。
2. CM 合约的数量和名义价值必须结合合约面值解释。
3. `bookDepth` 不能识别单个大单的挂出、撤单和队列位置。
4. 检查缺失、重复、时间戳连续性和 checksum。
5. 必须计入手续费、滑点、资金费率和延迟。

## 结论

优先研究：**OFI + OI 变化 + 1% 深度不平衡 + 短周期价格动量**。
